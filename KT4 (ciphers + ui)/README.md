# 🔐 Шифры Цезаря и Виженера (Java Swing)

Десктопное приложение на **Java Swing** для шифрования и расшифровки текстовых файлов с использованием двух классических алгоритмов криптографии: **шифра Цезаря** и **шифра Виженера**.

## 📌 Возможности

- 🔒 Шифрование и расшифровка текста.
- 🔑 Поддержка двух алгоритмов: Цезаря и Виженера.
- 🌍 Поддержка русского и английского алфавитов.
- 🔠 Сохранение исходного регистра букв.
- 📝 Сохранение цифр, пробелов и знаков препинания без изменений.
- 📂 Чтение исходного текста из файлов и сохранение результата в отдельные файлы.
- 🖥️ Графический интерфейс на Java Swing.

## 🛠️ Используемые технологии

- **Java 11+**
- **Java Swing**
- **File I/O** для чтения и записи текстовых файлов.

## 🚀 Как запустить проект

### 1. Требования

Перед запуском убедитесь, что у вас установлена Java JDK версии 11 или выше.

Проверить установленную версию можно командой:

```bash
java -version
```

### 2. Компиляция

Откройте терминал в папке проекта и выполните команду:

```bash
javac MainWindow.java CaesarCipher.java VigenereCipher.java
```

### 3. Запуск

После успешной компиляции запустите приложение:

```bash
java MainWindow
```

## 🖥️ Работа с приложением

В графическом интерфейсе доступны следующие параметры:

| Параметр | Описание |
|---|---|
| Шифр | Выбор алгоритма: Цезарь или Виженер |
| Режим | Шифрование или расшифровка |
| Входной файл | Путь к файлу с исходным текстом |
| Выходной файл | Путь для сохранения результата |
| Ключ | Числовой сдвиг или текстовый ключ |

### 🔑 Использование ключей

**Шифр Цезаря**

В качестве ключа используется целое число, определяющее количество позиций для сдвига букв в алфавите.

Пример:

```text
Ключ: 3
```

**Шифр Виженера**

В качестве ключа используется слово, состоящее только из букв. Ключ применяется последовательно к символам исходного текста.

Пример:

```text
Ключ: SECRET
```

Если ключ короче исходного текста, он повторяется до необходимой длины.

## 📁 Работа с текстовыми файлами

Приложение использует файловый ввод и вывод. Исходный текст считывается из выбранного файла, обрабатывается выбранным алгоритмом, после чего результат записывается в отдельный файл.

### Входной файл

Входной файл необходимо создать самостоятельно.

Например:

**Исходник_для_шифровки.txt**

Содержимое:

```text
Привет! Это пример текста для шифрования.
```

Для выбора файла нажмите кнопку «Обзор...» в поле «Входной файл».

### Выходной файл

Выходной файл создаётся автоматически после выполнения операции.

В поле «Выходной файл» необходимо указать путь и имя файла, в который будет записан результат.

Примеры названий:

- `результат_шифровки_цезарь.txt`
- `результат_виженера_шифровка.txt`
- `результат_расшифровки.txt`

Создавать выходной файл заранее не требуется.

## 🔄 Пример полного цикла работы

Рассмотрим шифрование и последующую расшифровку текста `Привет` с помощью шифра Цезаря.

### Шаг 1. Шифрование

1. Выберите алгоритм «Шифр Цезаря».
2. Установите режим «Шифрование».
3. Выберите входной файл `Исходник_для_шифровки.txt`.
4. Укажите выходной файл `результат_шифровки_цезарь.txt`.
5. Введите ключ `3`.
6. Нажмите кнопку «Выполнить».

Программа создаст файл с зашифрованным текстом.

### Шаг 2. Расшифровка

1. Выберите режим «Расшифровка».
2. В качестве входного файла укажите результат предыдущего шифрования.
3. Укажите новый выходной файл `результат_расшифровки.txt`.
4. Введите тот же ключ `3`.
5. Нажмите кнопку «Выполнить».

В результате программа восстановит исходный текст:

```text
Привет
```

Аналогичным образом можно проверить работу шифра Виженера, используя один и тот же текстовый ключ при шифровании и расшифровке.

## ⚙️ Особенности реализации

- Поддерживаются русский и английский алфавиты.
- Сохраняется регистр исходных букв.
- Пробелы, цифры и знаки препинания не подвергаются шифрованию.
- Позиции незашифровываемых символов сохраняются.
- Для расшифровки необходимо использовать тот же ключ, который применялся при шифровании.
- Ключ шифра Виженера должен содержать только буквы.

## 📖 Описание алгоритмов

**Шифр Цезаря** — метод шифрования, в котором каждая буква исходного текста заменяется другой буквой путём фиксированного сдвига по алфавиту.

**Шифр Виженера** — метод полиалфавитного шифрования, в котором величина сдвига каждой буквы определяется соответствующей буквой ключа.

Оба алгоритма являются классическими методами криптографии и используются в проекте в образовательных целях.
